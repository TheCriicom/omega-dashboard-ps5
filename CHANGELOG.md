# Changelog

## 2026.10.03

Prima versione pubblica.

- Home con giochi, homebrew websrv e payload ELF nella stessa fila.
- Store di homebrew: installazione di pkg, zip ed elf, voti, valutazioni,
  commenti, segnalazioni; libreria personale da JSON.
- Community: bacheca, gruppi, persone che potresti conoscere, tempo di gioco e
  classifica degli amici.
- Party con chat e voce (Opus), inviti a giocare, stato personalizzato.
- Privacy: blocchi, segnalazioni, chi può scriverti, esportazione ed
  eliminazione dell'account.
- Scelta del server dalle Impostazioni.
- Server con Docker Compose, HTTPS opzionale con Caddy e pannello di
  moderazione web.
